# PROJECT BRIEF: NICOLAS PARIS WEB

## Resumen

Nicolas Paris web es un proyecto nuevo para una experiencia inmobiliaria premium.
El objetivo es construir un sitio con presencia de marca, catalogo de propiedades
y caminos claros de contacto para compradores, inquilinos y propietarios.

## Principios

- La propiedad es protagonista: fotografia, datos claros y recorrido simple.
- La marca debe sentirse premium, sobria y confiable.
- El sitio debe convertir sin sentirse invasivo.
- La experiencia mobile debe estar al nivel de la desktop.
- La documentacion debe separar producto, diseno, datos y decisiones tecnicas.

## Alcance inicial

- Sitio publico.
- Catalogo/listado de propiedades.
- Detalle de propiedad.
- Secciones institucionales.
- Captura de consultas.
- Base futura para panel administrativo si el alcance lo requiere.
