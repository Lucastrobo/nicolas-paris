# REQUIREMENTS

## Requisitos de experiencia

- El primer viewport debe comunicar marca inmobiliaria premium de inmediato.
- Las propiedades deben poder explorarse sin friccion en mobile y desktop.
- Las llamadas a la accion deben ser visibles, claras y consistentes.
- El contenido debe evitar copy generico y enfocarse en confianza, ubicacion y valor.
- Las imagenes deben tener protagonismo real y no sentirse decorativas.

## Requisitos funcionales

- Listado de propiedades con filtros basicos.
- Pagina de detalle con galeria, datos principales, descripcion y contacto.
- Seccion de tasaciones con formulario o CTA directo.
- Seccion de contacto con canales principales.
- Navegacion simple entre operaciones: venta, alquiler y desarrollos.

## Requisitos de contenido

- Copy sobrio, premium y directo.
- Datos de propiedades estructurados.
- Fotografias reales o assets aprobados por marca.
- Textos institucionales breves y confiables.

## Requisitos tecnicos pendientes de definicion

- Stack frontend definitivo.
- Fuente de datos para propiedades.
- CMS, panel admin o carga manual inicial.
- Hosting y dominio.
- Integraciones: WhatsApp, formularios, analytics, mapas.

## Pendientes de Figma

- Inventario de frames.
- Componentes reutilizables.
- Tokens de color y tipografia.
- Breakpoints y comportamiento responsive.
- Assets exportables.
