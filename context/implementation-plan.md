# IMPLEMENTATION PLAN

## Fase 0: Discovery

- Destrabar acceso a Figma.
- Auditar pantallas y componentes.
- Confirmar alcance funcional de fase 1.
- Definir stack y fuente de datos.

## Fase 1: Base del proyecto

- Crear app base.
- Configurar estilos, tipografias y tokens.
- Definir estructura de rutas.
- Crear componentes layout principales.

## Fase 2: Sitio publico

- Home.
- Listado de propiedades.
- Detalle de propiedad.
- Tasaciones.
- Nosotros/contacto.

## Fase 3: Datos e integraciones

- Modelo de propiedad.
- Fuente de datos.
- Formularios de contacto.
- WhatsApp, mapas y analytics.

## Fase 4: QA y salida

- Responsive QA.
- Performance y SEO.
- Relevamiento de contenido final.
- Deploy inicial.
